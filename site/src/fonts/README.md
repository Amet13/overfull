# Fonts

Latin Modern Roman, the typeface of TeX and of the Overfull templates, has no
`@fontsource` package, so its files are kept here. They come from the
`latex.css` 1.12.0 npm package and are under the GUST Font License
(<https://www.gust.org.pl/fonts/licenses>).

Fira Sans and Commit Mono come from their `@fontsource` packages, imported in
`src/layouts/Base.astro`.
